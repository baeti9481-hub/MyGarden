# MyGarden
MyGarden merupakan website e-commerce. Project ini dibuat untuk keperluan UAS Semester 4 serta untuk pembelajaran dan pengembangan

# fitur utama
- Login dan registrasi cepat menggunakan akun google (Google OAuth)
- Katalog Produk lengkap dengan harga, stok, dan deskripsi
- keranjang belanja dan proses chekout
- perhitungan ongkos kirim otomatis menggunakan API RajaOngkir
- manajemen produk dan pesanan oleh admin
- Riwayat transaksi pelanggan

# Teknologi
- Laravel
- mysql
- Bootstrap/ Blade Template
- Google OAuth
- RajaOgkir API
